# 📦 Amazon Bootstrap — E-Commerce Homepage UI

A replica of Amazon's homepage design, engineered using the Bootstrap 5 responsive framework and custom CSS styling.

## 🛠️ Main Technologies Used

- **Structure:** HTML5
- **Styling Framework:** Bootstrap 5 & CSS3

---

## ✨ Key Features

- 🏗️ **Bootstrap Grid System:** Flexible layout structure adapting to screens of all sizes.
- 🛒 **Multi-Category Product Cards:** Grouped deal boxes and multi-item offer rows.
- 🧭 **Multi-tiered Navigation:** Primary and secondary header navigation bars.

## 📦 Dependencies

- **Bootstrap 5 CDN:** Included via `<link>` stylesheet and script tags.
